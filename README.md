# Introduction

**athina** is a data analysis package for spectromicroscopy/microspectroscopy experiments based on Igor Pro 9 or later. It can analyse datasets from PEEM, LEEM, XPEEM, μ-XPS, PED, ARPES and more image-based data.

It has built-in support for reading Elmitec's proprietary .dat files, EMMENU tif/tif stacks, NeXus files and more.
